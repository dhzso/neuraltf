# Roadmap

> Development phases for BioForge.
>
> Phases are sequential. Each phase builds on the completed deliverables of
> the previous one. Scope and timelines for future phases are provisional
> and may be revised as the project evolves.

---

## Phase 1: Foundation

Establish the repository as a professional software product.

- Repository metadata (README, CHANGELOG, LICENSE, .gitignore)
- Documentation foundation (Architecture, Roadmap, Development guide)
- Directory structure

**Status:** In progress

---

## Phase 2: Base Environment

Build the containerized foundation.

- BioForge base image on Debian Slim
- Python 3.11 runtime
- System-level dependencies
- Docker Compose configuration

**Status:** Not started

---

## Phase 3: Scientific Stack

Install and validate the core scientific Python ecosystem.

- NumPy, SciPy, pandas
- scikit-learn
- Visualization libraries (matplotlib, seaborn, plotly)
- Jupyter environment

**Status:** Not started

---

## Phase 4: AI Integration

Integrate AI-assisted analysis capabilities.

- Prompt management system
- Persistent memory store
- AI-assisted analysis workflows
- Configuration management for AI models

**Status:** Not started

---

## Phase 5: Bioinformatics Modules

Implement domain-specific analysis pipelines.

- Single-cell RNA-seq pipeline
- Bulk RNA-seq pipeline
- Spatial transcriptomics pipeline
- ATAC-seq pipeline
- Gene regulatory network inference
- Report generation

**Status:** Not started

---

## Phase 6: CLI

Build the command-line interface.

- Pipeline execution commands
- Project management commands
- AI-assisted analysis commands
- Configuration and environment management

**Status:** Not started

---

## Phase 7: Automation

Automate repetitive workflows and quality assurance.

- Automated pipeline orchestration
- Continuous integration for code quality
- Automated report generation
- Dataset caching and management

**Status:** Not started

---

## Phase 8: Open-source Release

Prepare BioForge for public release.

- Contributor guidelines (CONTRIBUTING.md)
- Style guide (STYLE_GUIDE.md)
- Automated testing and validation
- Release packaging and versioning
- Public documentation

**Status:** Not started
